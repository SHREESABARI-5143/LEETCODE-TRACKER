# Leetcode Tracker Application

A comprehensive application for tracking Leetcode progress, specifically designed for managing student metrics, analyzing contest performance, and generating reports.

## Structure

This repository is organized into two main parts:

- **/frontend**: A React-based web interface for displaying dashboards, student profiles, and leaderboards.
- **/backend**: A Node.js server that handles the business logic, API requests, data synchronization, and interacts with the database.

## Features
- **Student Dashboard**: Track individual problem-solving statistics and history.
- **HOD / Proctor Dashboards**: Detailed analytics and aggregated performance reports for groups.
- **Contest Analytics**: Analyze historical and real-time contest results.

## Getting Started

### Prerequisites
- Node.js
- Package manager (npm or yarn)

### Installation
1. Clone the repository.
2. Install dependencies for the backend:
   ```bash
   cd backend
   npm install
   ```
3. Install dependencies for the frontend:
   ```bash
   cd frontend
   npm install
   ```

*(Please make sure to set up your environment variables as per the `.env.example` in the backend directory before running the application).*
